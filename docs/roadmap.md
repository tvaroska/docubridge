# Roadmap (`docubridge`)

Historical architectural decisions live in [DECISIONS.md](../DECISIONS.md), non-negotiable invariants in [CRITICAL.md](../CRITICAL.md), feature definitions in [features.md](features.md), and design specifications under [design/bridge.md](../design/bridge.md).

## Where we are

`docubridge` (`v1.15.0`) ships a 6-Zone governed A2A document mediation core across all 14 dual-mode (`local`/`gcp`) Hexagonal `Port` boundaries (`sessions`, `task_store`, `exchange_store`, `skill_registry`, `memory_bank`, `scheduler`, `a2a_client`, `extraction`, `email_ingress`, `audit_vault`, `operational_store`, `action_inbox`, `agent_gym`, `knowledge_catalog`), backed by `1,887` passing unit/contract tests (`>=90%` coverage), `56` credential-free `terraform test` checks, Schema Refinery (`P8-1`–`P8-8`), generic `ScenarioEngine` (`P9-1`–`P9-3`), and completed **`P10` (`v1.15.0`)** hardening (fail-closed `K_SERVICE` `Option 2B` signed-cookie auth across all mutating routes, standalone/co-located single-bucket `gs://<project-id>` Terraform + Python prefix/WORM adapters held ready locally without live deploy yet, `bq-eval` `v0.2.3` SQL alignment, and `uv:0.12.24` / `HEALTHCHECK` / Trivy / `Decimal` approval limits). Next graduation milestones are **`P11` (`v1.16.0`)** (collection strategy sufficiency + canonical A2A counterparty dial-out coordinated with `docubridge-examples`) and **`P12` (`v1.17.0`)** (Tier-2 `ui-design` governance and zero standards debt).
