# Roadmap (`docubridge`)

Historical architectural decisions live in [DECISIONS.md](../DECISIONS.md), non-negotiable invariants in [CRITICAL.md](../CRITICAL.md), feature definitions in [features.md](features.md), and design specifications under [design/bridge.md](../design/bridge.md).

## Where we are

`docubridge` ships a 6-Zone governed A2A document mediation core across all 14 dual-mode (`local`/`gcp`) Hexagonal `Port` boundaries (`sessions`, `task_store`, `exchange_store`, `skill_registry`, `memory_bank`, `scheduler`, `a2a_client`, `extraction`, `email_ingress`, `audit_vault`, `operational_store`, `action_inbox`, `agent_gym`, `knowledge_catalog`), backed by `1,864` passing unit/contract tests (`>=90%` coverage), `46` credential-free `terraform test` checks, Schema Refinery (`P8-1`–`P8-8`), generic `ScenarioEngine` (`P9-1`–`P9-3`), and hygiene/quickstart hardening (`P10-1`–`P10-2`). Active graduation work completes **`P10` (`v1.15.0`)** first — fail-closed `K_SERVICE` signed-cookie auth (`Option 2B`) across all mutating routes, standalone-installable single-bucket `gs://<project-id>` Terraform + Python GCS adapters (held ready locally without deploying yet), canonical `bq-eval` SQL alignment, and container/CI/`Decimal` hardening — then moves to **`P11` (`v1.16.0`)** (collection strategy sufficiency + canonical A2A counterparty dial-out coordinated with `docubridge-examples`) and **`P12` (`v1.17.0`)** (Tier-2 `ui-design` governance and zero standards debt).
