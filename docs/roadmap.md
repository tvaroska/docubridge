# Roadmap (`docubridge`)

Historical architectural decisions live in [DECISIONS.md](../DECISIONS.md), non-negotiable invariants in [CRITICAL.md](../CRITICAL.md), feature definitions in [features.md](features.md), and design specifications under [design/bridge.md](../design/bridge.md).

## Where we are

`docubridge` ships a 6-Zone governed A2A document mediation core across all 14 dual-mode (`local`/`gcp`) Hexagonal `Port` boundaries (`sessions`, `task_store`, `exchange_store`, `skill_registry`, `memory_bank`, `scheduler`, `a2a_client`, `extraction`, `email_ingress`, `audit_vault`, `operational_store`, `action_inbox`, `agent_gym`, `knowledge_catalog`), backed by `1,859` passing unit/contract tests (`>=90%` coverage), `46` credential-free `terraform test` checks, Schema Refinery (`P8-1`–`P8-8`), and generic `ScenarioEngine` (`P9-1`–`P9-3`). Active graduation work completes `P9-4` (`strategy.yaml` sufficiency), hardens hygiene, fail-closed `K_SERVICE` signed-cookie showcase auth (`Option 2B`), and canonical A2A counterparty calls (`P10` / `v1.15.0`), and prepares single-bucket co-located `Showcases` Terraform (`docubridge` + `docubridge-examples` + `bq-eval` in one GCP project, held ready locally without deploying yet), Tier-2 `ui-design` compliance, and zero standards debt (`P11` / `v1.16.0`).
