# Roadmap (`docubridge`)

Historical architectural decisions live in [DECISIONS.md](../DECISIONS.md), non-negotiable invariants in [CRITICAL.md](../CRITICAL.md), feature definitions in [features.md](features.md), and design specifications under [design/bridge.md](../design/bridge.md).

## Where we are

`docubridge` (`v1.17.0`) ships a 6-Zone governed A2A document mediation core across all 14 dual-mode (`local`/`gcp`) Hexagonal `Port` boundaries (`sessions`, `task_store`, `exchange_store`, `skill_registry`, `memory_bank`, `scheduler`, `a2a_client`, `extraction`, `email_ingress`, `audit_vault`, `operational_store`, `action_inbox`, `agent_gym`, `knowledge_catalog`), backed by `2,015` passing unit/contract tests (`>=90%` coverage), `57` credential-free `terraform test` checks, Schema Refinery (`P8-1`–`P8-8`), generic `ScenarioEngine` (`P9-1`–`P9-3`), **`P10` (`v1.15.0`)** security/IaC/SQL/supply-chain hardening, **`P11` (`v1.16.0`)** declarative collection strategy (`ADR-14`/`ADR-15`) and canonical A2A v1.0 counterparty dial-out, and completed **`P12` (`v1.17.0`)** (Tier-2 `ui-design` governance with `.stitch/DESIGN.md`, offline bundled fonts, 4 Vite favicons, MSVG-safe SVG, executed Playwright E2E CI gate, zero standards debt in `tests/standards_debt.json`, `SCENARIO_LITERAL_ALLOWLIST = {}`, `<800` non-blank LOC across all modules, `mypy --strict`, all 16 Ruff rule families, and `0` narration comments). Milestones `P10`–`P12` are shipped; `P13` (`v1.18.0`) and `P14` (`v1.19.0`) are implemented locally on `main` (pending release); `P15` (review findings of 2026-11-21) is open.
