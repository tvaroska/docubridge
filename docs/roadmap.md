# Roadmap (`docubridge`)

Historical architectural decisions live in [DECISIONS.md](../DECISIONS.md), non-negotiable invariants in [CRITICAL.md](../CRITICAL.md), feature definitions in [features.md](features.md), and design specifications under [design/bridge.md](../design/bridge.md).

## Where we are

`docubridge` (`v1.16.0`) ships a 6-Zone governed A2A document mediation core across all 14 dual-mode (`local`/`gcp`) Hexagonal `Port` boundaries (`sessions`, `task_store`, `exchange_store`, `skill_registry`, `memory_bank`, `scheduler`, `a2a_client`, `extraction`, `email_ingress`, `audit_vault`, `operational_store`, `action_inbox`, `agent_gym`, `knowledge_catalog`), backed by `1,905` passing unit/contract tests (`>=90%` coverage), `56` credential-free `terraform test` checks, Schema Refinery (`P8-1`–`P8-8`), generic `ScenarioEngine` (`P9-1`–`P9-3`), **`P10` (`v1.15.0`)** security/IaC/SQL/supply-chain hardening, and completed **`P11` (`v1.16.0`)** (declarative `assets/strategy.yaml` + deterministic `bridge/strategy/` evaluator, `CONTRACT_VERSION = "1.5"` `ExchangeTurn.sufficiency`, recommendation-only waivers per `ADR-14`/`ADR-15`, post-split `agents/address/*` doc cleanup, and canonical A2A v1.0 `SendMessage` counterparty dial-out across `fnb`, `carrier-a`, and `carrier-b` with `/ebc` shim badges). Next graduation milestone is **`P12` (`v1.17.0`)** (Tier-2 `ui-design` governance and zero standards debt).
